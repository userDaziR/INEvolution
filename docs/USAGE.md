# 使用指南

## 1. 启动

```bash
cd INEvolution
python server.py
```

打开 <http://127.0.0.1:8080/>。

- 页面通过 `/api/files` 读取内容文件与节点树，通过 `data/graph.json` 恢复颜色、坐标、父子关系和星链。
- 如果使用了不同端口，页面上的报错提示会提醒检查 `server.py` 是否正在运行。
- 当前仓库里的 `notes/planets/语言.md`、`notes/planets/领域.md` 已经关联到同名星球；新增节点不会自动从 `notes/` 里导入。

## 2. 五层结构

```text
根星域
└── 星系
    └── 星球
        └── 板块
            └── 国家
                └── 城市
```

| 当前页面 | 显示节点 | 双击节点后 |
| --- | --- | --- |
| 根星域 | 星系 | 进入星系，显示星球 |
| 星系 | 星球 | 播放放大特效，进入板块球体 |
| 星球 | 板块 | 播放放大特效，进入国家平面 |
| 板块 | 国家 | 播放放大特效，进入城市平面 |
| 国家 | 城市 | 叶子节点：打开内容或提示创建 |

节点不再等同于一个 `.md` 文件。星球可以没有任何内容文件；内容是在需要时附加到节点上的。

## 3. 内容按需创建

### 右键「编辑内容」

在任何节点（星系、星球、板块、国家、城市）上右键 → `编辑内容`：

1. 如果内容文件不存在，会在 `notes/` 下按类型创建规范路径；
2. 节点 `md` 字段记录该路径（规范依赖）；
3. 右侧打开编辑模式。

路径规则：

```text
notes/galaxies/<node-id>.md
notes/planets/<node-id>.md
notes/sectors/<node-id>.md
notes/countries/<node-id>.md
notes/cities/<node-id>.md
```

节点 ID 稳定；重命名节点不会移动文件。文件存在后，单击节点会在右侧打开阅读面板。

### 单击行为

- **有内容文件**：左侧聚焦节点，右侧展开 Markdown 阅读面板。
- **没有内容文件**：只聚焦节点，不打开面板。

右侧面板的「编辑」切换到编辑模式；「保存」写回文件。`Ctrl + S` 也可以保存。

右侧面板顶部还有「删除」按钮：它**只删除当前节点的 Markdown 内容文件**，节点本身保留。删除后该节点回到“无内容”状态，单击只聚焦；需要时可以再次右键「编辑内容」重新创建。

### 内容文件

`notes/` 支持子目录，但推荐保持按类型分目录：

```text
notes/
├── planets/
│   ├── 语言.md
│   └── 领域.md
├── sectors/
├── countries/
└── cities/
```

`galaxies/`、`sectors/`、`countries/`、`cities/` 可能一开始不存在，第一次编辑内容时会自动创建。

## 4. 新建节点

### 从空白处新建

在任意层级的空白处右键：

- 根星域 → `新建星系`
- 星系 → `新建星球`
- 星球（板块球体）→ `新建板块`
- 板块（国家平面）→ `新建国家`
- 国家（城市平面）→ `新建城市`

输入名称即可。新节点默认没有内容文件；需要时再右键「编辑内容」。

### 从节点菜单新建子节点

右键节点 → `新建{下一层}`，会在该节点下创建子节点。例如：

- 右键星球 → `新建板块`
- 右键板块 → `新建国家`
- 右键国家 → `新建城市`

这允许你在当前层直接给另一个父节点添加子节点，而不必先进入它。

### 空白层级

中间层可以为空。例如一个还没有板块的星球会显示板块球体，但球面上没有板块；右键空白处新建第一个板块即可。

## 5. 板块球体

双击星球进入板块页面。

### 面积规则

球体面积固定。每个板块的面积由其子节点「国家」数量决定：

```text
板块面积 / 球面总面积 = 该板块国家数 / 所有板块国家数之和
```

例如：

- 板块 A 有 2 个国家，板块 B 有 1 个国家；
- A 的球面面积是 B 的 2 倍；
- A 与 B 的面积刚好铺满整个球面。

空板块（0 个国家）使用最小权重 1，否则在创建第一个国家前会不可见。这个兜底会在图例里显示为 `0 国`。

### 图例

板块页面左侧的「板块分布 // SECTORS」列出：

- 颜色
- 板块名
- 国家数
- 面积百分比

百分比是球面面积的精确读数。转动球体可以查看背面板块。

### 自由旋转与点击

- 球体使用四元数 trackball 旋转，可以向任意方向拖动；不再有俯仰角限制或转到某个角度卡住的问题。
- 点击命中基于**当前可见的曲面网格**，不是板块中心。因此只要板块有一部分露在正面，就可以点击它。
- 单击板块只高亮并暂停自动旋转，不会强制转动球体；聚焦一个板块后，仍可继续点击旁边的其他板块。
- 板块标签会落在该板块当前可见面积最大的网格上，转动时跟随可见区域。

### 操作

- **拖拽**：自由旋转球体
- **滚轮**：缩放
- **单击板块**：高亮聚焦；如果该板块有内容，右侧打开内容面板
- **双击板块**：放大进入国家平面
- **右键板块**：编辑内容 / 新建国家 / 重命名 / 配色 / 星链 / 删除
- **右键空白**：新建板块 / 返回上一层 / 重置视角

板块球体使用 Canvas 2D 的高斯泼溅风格近似：缓存 splat 球体纹理 + 动态高斯粒子 + 经纬网格。表面加入方向光、边缘暗化、镜面高光与边缘光；板块边界是细亮线与柔和辉光，没有粗黑分隔线。

## 6. 国家平面

双击板块进入国家页面。

- 页面是平面：相机固定正面，不环绕；节点 `z=0`。
- 国家节点是 3D 规则多面体（正八面体 / 正二十面体），在固定倾斜范围内缓慢摆动。
- 单击国家：聚焦；有内容时打开右侧面板。
- 双击国家：播放放大特效，进入城市平面。
- 右键国家：编辑内容 / 新建城市 / 重命名 / 配色 / 星链 / 删除。
- 右键空白：新建国家 / 返回上一层 / 重排 / 重置视角。

## 7. 城市平面

双击国家进入城市页面。

- 页面是平面（固定正面相机）。
- 城市节点是 3D 正方体，半透明面 + 线框，缓慢摆动。
- 城市是叶子节点：没有下一层。
- 单击城市：聚焦；有内容时打开右侧面板。
- 双击城市：打开内容；没有内容时提示右键「编辑内容」。
- 右键城市：编辑内容 / 重命名 / 配色 / 星链 / 删除。

## 8. 聚焦与右侧内容面板

### 聚焦

- 单击节点：聚焦；图谱/平面层镜头平滑移动到节点，板块球体层高亮对应板块并暂停自动旋转（不会强制转向，方便继续点击其他板块）。
- 点击空白：关闭右侧内容面板并取消聚焦。
- `Esc`：先关闭内容，再取消聚焦，再返回上一层。

### 右侧面板

- 有内容文件的节点：单击后右侧展开 Markdown 阅读面板。
- 「编辑」切换编辑模式；textarea 内可写 Markdown。
- 「保存」或 `Ctrl + S` 写回文件。
- 「删除」只删除当前 Markdown 内容文件，节点保留；确认框会明确提示。
- 关闭、切换节点、进入下一层时，如果有未保存修改会弹窗确认。
- 面板打开时左侧星图仍可交互；点击另一个节点会切换内容或收起面板。
- 面板宽度为 `clamp(380px, 42vw, 720px)`；窄屏会占满整屏。

Markdown 支持 GFM 表格、任务列表、代码高亮、引用等。marked / DOMPurify / highlight.js 来自 CDN；完全离线时阅读器会降级，但图谱本身仍可工作。

## 9. 星链

- 右键节点 → `添加星链`，然后点击同一层级的另一个节点。
- 右键节点 → `删除星链`，选择要断开的节点。
- 根星域连接星系；星系内连接星球；板块层连接板块；国家/城市层同理。
- 板块层的星链渲染为球体外侧的弧线。

星链在视觉上是白色到绿色的流动数据流：渐变底光、流动虚线、数据包拖尾和二进制字符。

## 10. 重命名、配色、移动、删除

- **重命名**：右键节点 → `重命名`。内容路径由 ID 固定，不会移动文件。
- **配色**：右键节点 → `更改配色`，拖动色相或点击色板。板块/国家/城市默认按层级调色板分配，自定义色优先。
- **移动星球**：右键星球 → `移入星系` → 选择目标星系（仅星球支持）。
- **删除**：
  - 右侧面板「删除」只删除内容文件，保留节点。
  - 选中节点后按 `Delete` 或 `Backspace` 删除节点本身（有子节点时阻止）。
  - 有子节点的节点不能直接删除；先删除或移走子节点。
  - 删除节点时会同时删除其内容文件（如果存在）。
  - 删除城市不会影响国家；删除国家要求没有城市。
  - 在 Markdown 编辑框、名称输入框等输入控件内按 `Backspace` / `Delete` 只会编辑文本，不会删除节点。

## 11. 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Esc` | 关闭浮层 / 关闭内容 / 取消聚焦 / 返回上一层 |
| `Delete` / `Backspace` | 删除当前选中节点（有子节点时阻止；输入框内不触发） |
| `Space` | 图谱自动环绕 / 板块球体自动旋转 |
| `R` | 重置视角 |
| `+` / `-` | 放大 / 缩小 |
| `Ctrl + S` | 保存当前编辑的内容 |
| 鼠标拖拽 | 环绕 / 旋转球体 |
| `Shift` + 拖拽 | 平移 |
| 滚轮 | 缩放 |

## 12. 数据备份与重置

需要备份：

- `notes/`：所有内容
- `data/graph.json`：节点树、颜色、坐标、父子关系、星链、内容路径

恢复默认布局：

- 顶部「重排」会重新随机布置当前层节点并保存；板块球体布局由面积算法决定，不能手动重排。
- 删除 `data/graph.json` 会丢失节点树、颜色、星链与布局；内容文件本身不受影响，但需要重新建立节点与内容的关联。

## 13. 常见问题

**页面提示无法加载数据**

确认 `server.py` 正在运行，并且访问的是它输出的地址（默认 `http://127.0.0.1:8080/`）。如果 8080 被旧版本占用，先停止旧进程。

**新建节点后刷新丢失**

确认使用的是当前 `server.py` 和当前 `web/app.js`，而不是旧版 `knowledge-graph-server.py` / 内联旧脚本。旧版不理解 v2 节点树。

**节点没有内容，单击只聚焦**

这是预期行为。右键节点 → `编辑内容` 创建文件后，单击才会打开右侧面板。

**在 `notes/` 里新建了 `.md`，但没有出现节点**

从 0.4.0 起，节点由 `data/graph.json` 的树定义，不再扫描笔记自动创建星球。请通过右键菜单创建节点并编辑内容，或使用规范路径把内容关联到已有节点。

**板块面积看起来不按比例**

单个半球无法同时展示球体背面的板块；请结合左侧图例的百分比，或拖动球体查看。面积算法在 UV 球面上严格按国家数分配。

**端口被占用**

```bash
python server.py --port 8081
```

然后访问 `http://127.0.0.1:8081/`。

**Markdown 没有样式 / 没有代码高亮**

检查是否能访问 unpkg / staticfile CDN。图谱不依赖 CDN，阅读器会降级。

**想换回浅色主题？**

在 `web/index.html` 的 `HACKER / MATRIX THEME OVERRIDES` 区段删除或覆盖对应变量即可。
